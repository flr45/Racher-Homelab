# Racher OS – Sprint 1

## Leveret

- Responsivt mørkt designsystem
- Sidebar og mobilnavigation
- Dashboard med CPU, RAM, SSD, temperatur og oppetid
- Docker- og backupstatus
- Appoversigt med hurtige links
- Kommandopalette via `Cmd/Ctrl + K`
- Live opdatering fra `/api/status` hvert 30. sekund uden fuld genindlæsning
- Fortsat skrivebeskyttet betjening
