# Racher OS 0.1

Racher OS er den nye visuelle retning for homelabbets Control Center.

## Denne version

- Nyt responsivt dashboard med sidebar
- Systemkort for CPU, RAM, disk, temperatur og oppetid
- Docker-status
- Hurtig adgang til apps
- Backup-status
- Forberedt til Cloudflare Access

Version 0.1 er fortsat skrivebeskyttet. Administrative handlinger tilføjes først efter deployment og sikkerhedstest på Raspberry Pi.
