# 🚀 Racher-HomeLab

Mit private HomeLab bygget omkring en Raspberry Pi 5.

Målet er at samle alle mine projekter på én server med høj driftssikkerhed, nem backup og mulighed for at udvide løbende.

---

# 🎯 Formål

HomeLab'et skal fungere som min centrale server til:

- Hosting af egne webapplikationer
- Udvikling og test
- Backup
- Overvågning
- Smart Home
- Personlig cloud

---

# 🖥 Hardware

## Server

- Raspberry Pi 5 (8 GB)
- Pimoroni NVMe Base
- 1 TB NVMe SSD (2280)
- Raspberry Pi Active Cooler

---

# 🛠 Infrastruktur

Første tjenester der installeres:

- Docker
- Portainer
- Nginx Proxy Manager
- PostgreSQL
- Redis
- Uptime Kuma
- Tailscale
